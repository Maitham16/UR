# F08 — model evidence and portable tool discovery

Status: shipped and release verified; see [F14](F14.md) for packaged checks.
Tested capability evidence is not a guarantee for every provider/model combination.

The existing `model-doctor` command now supports `--probe`, `--profile`,
`--provider`, `--timeout-ms`, and JSON output. Probes use the production provider
adapter and record actual typed tool-result round trips, structured output,
visible progress across a reported output boundary, and cancellation after a
stream content delta. Failure, timeout and unobserved behavior remain distinct.
Saved schema-1 profiles are scoped to provider/model/sanitized endpoint and
flagged stale after seven days. Context is labeled provider-advertised, not
measured. Profile defaults are advisory; they do not block model choices or
silently change the user's execution or permission settings.

Native adapters now use ordinary JSON tool definitions returned by ToolSearch.
Discovery is selected automatically when the available tool schema catalog
crosses the existing context-relative threshold. Existing ENABLE_TOOL_SEARCH
force/auto/false settings remain supported. Discovered definitions persist
through normal conversation and compaction. Unsupported Anthropic tool-reference
blocks/beta flags are never sent by native provider adapters. The original tool
objects and execution permission registry remain authoritative. Models select
which tools to discover and call.

## Limits and integration

One small successful sample is evidence of that sample, not a reliability
estimate for every task/model. No other configured model was live-probed.
Client cancellation and iterator closure do not prove provider-side billing
termination. Exact-context capacity is not measured. Failed capability results
remain diagnostics and recommendations, not mandatory fallback decisions.

Technical/04 and technical/05 document actual behavior. Canonical CLI flags are
wired and summarized in USAGE and CONFIGURATION; generated `.ur/model-profiles/`
state is ignored by Git.

Resource read: Anthropic's advanced tool use article motivated deferred schema
selection; native providers use their existing ordinary message formats rather
than claiming support for provider-specific tool-reference APIs.
