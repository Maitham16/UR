# F13 — Optional team operations

Status: locally verified, including real HTTP transport; release/platform
qualification and any commercial authorization remain separate.

Opt-in `UR_ACP_TEAM_POLICY` adds controls to the existing ACP HTTP dispatcher.
It must be an absolute administrator-controlled file outside the workspace;
the external `UR_REMOTE_STATE_DIR` must be private. Existing operator/device
identity, session scope, expiry and revocation are reused. No policy means no
new team checks, quota or environment changes. No duplicate CLI/scheduler was
introduced, and LICENSE is unchanged.

Implemented:

- Viewer/member/reviewer roles, operator-only administration/audit export.
- Durable shared/member cumulative and concurrent prompt-attempt quotas.
  This is an explicit request unit, not dollars, tokens or nested model calls.
  Exact prompt/session/principal request binding prevents duplicate charges or
  execution. Orphan quota receipts fail closed. Dead owners retain unknown
  concurrency; operator reconciliation preserves the total charge and records
  a review-reason digest. Live-owner reservations cannot be released.
- Optional administrator-reviewed automation receipts bind exact prompt hash,
  session and principal through the existing `session/prompt` method.
- Literal per-run environment allowlists plus OS/runtime basics; ambient proxy
  credentials/unclassified variables are excluded too. The operator token and
  control path never reach workers. Private UR config is per durable session.
  The environment is never mutated globally.
- Redacted, fsynced audit-before-dispatch, completion/failure records and
  bounded cursor export with sequence/hash-chain validation. Corrupt/torn audit
  prevents dispatch. No prompt, output or credential value is exported.

Canonical HTTP additions: `team/status`, `team/audit`, `team/reconcile`.
Team execution uses durable `session/prompt` with `stream:true`; legacy direct
tool/task execution is refused only in opted-in team mode because it would
bypass accounting. Normal tool permissions and agent strategy remain intact.

The non-socket suite passed 34 tests/133 assertions, including an actual killed
reservation owner, competing controller processes, tampered review/audit
inputs, role/revocation rules, accepted-attempt budget persistence and actual
default-ACP-runner child environment forwarding. The root full-access real HTTP
qualification passed 1 test/14 assertions in ~701 ms, logged at
`/private/tmp/ur-frontier-team-http.log`: viewer denied, member/reviewer approval
separation, exactly one benign write, idempotent request delivery, shared quota
exhaustion, redacted export and revoked-credential 401. The restricted agent
executor could not bind loopback; no test assertion was weakened. No real model,
external network service or credential was used. Typecheck/lint passed; root
also independently reviewed the integration and new module strict typing.

Scope: local CLI/stdio work and nested model calls are outside these request
quotas. Environment filtering/private UR config do not independently isolate
host files, HOME, external CLI login stores, hooks, MCP or same-user host access.
Protect control state with the chosen OS/container boundary. Local audit chains
are not external signatures or evidence against administrator replacement or
valid-prefix truncation. Commercial use requires the copyright holder's prior
written permission; functionality does not grant a commercial license.
