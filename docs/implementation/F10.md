## Published interactive observation

On 2026-10-21, the published Homebrew 1.87.0 executable completed fresh setup
with Node and Bun absent from PATH, displayed the first-task guidance, checked
the selected Ollama connection, and answered a small project's test-command
question using `minimax-m3.1-flash:cloud`. It read `package.json` and the test
file and correctly identified `npm test` / `node --test`. The two source files
were unchanged. This is one bounded observation, not an all-provider success
rate: the model also ran a read-only `ls` despite the prompt asking it not to
run commands. No compulsory execution strategy was added in response.

The readiness report hid angle-bracket command arguments because its output
was interpreted as Markdown/HTML. The follow-up renders plain text and JSON
inside a literal code block. A rebuilt 1.87.1 native interactive session
verified that `<id>`, `<name>` and `<session-id>` are visible. CLI readiness
data and execution permission choices are unchanged.
