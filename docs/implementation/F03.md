# F03 browser fixture execution

Status: locally verified; final integration/release qualification remains open.

The canonical browser-qa command now uses real isolated Playwright contexts,
interaction steps, executable predicates and per-viewport evidence. Unknown
natural-language assertions cannot pass. Browser errors, failed assertions,
cancellation and missing artifacts produce failure. Local command results have
an optional exitCode consumed by the CLI adapter; interactive use does not set
global process exit state. Shared browser executable discovery serves both the
Browser tool and fixture runner. Example fixtures and technical documentation
now describe actual behavior; runtime artifacts are ignored by git.

Validation: `bun test test/browserQa.test.ts --timeout 120000` with
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH set to the installed cached Chromium and
UR_REQUIRE_BROWSER_QA_TESTS=1: **6 pass, 0 fail, 28 assertions**. Tests launch a
real browser, interact with a rendered page at two viewports, check nonboolean
predicate rejection, fail broken rendering/console/page errors/overflow, verify
artifact hashes and cancellation. CI installs Chromium and requires these tests.

Source API references are linked in technical/10. The built CLI returned exit
0 for the passing rendered fixture and exit 1 for the same fixture with a false
assertion. Native macOS candidate qualification additionally passed the public
browser fixture preview without external JavaScript runtimes. The complete
release/native matrix remains in F14's release gate.
