# F09 — Optional safe autonomy and security evidence

Status: shipped and release verified on macOS/Linux; see [F14](F14.md).
Windows native qualification remains deferred.

`ur safety init --preset sandboxed [--allow-domain HOST]` creates a separate
private settings file with exclusive creation. It never enables it, overwrites
it, or changes existing permission choices. Explicit `--settings` opts into
required sandboxing, disabled unsandboxed fallback, trusted strict proxy egress,
private-file roots and current secret-like environment names (no values).
Repository-local copies cannot enable the trusted credential/strict-egress
controls. Existing permission-allowed hosts/read exceptions and separate
native-file-tool, hook, MCP and external CLI boundaries remain relevant.

`ur safety status` includes honest availability, scope and attestation limits.
`ur safety audit --json` exposes a versioned offline suite: 8 malicious text
fixtures, 4 benign fixtures and 5 policy decisions. Current results detect 8/8
attacks with 0/4 benign false positives. Framing preserves benign content and
keeps the session evidence ledger untouched. This is detector/policy regression
evidence, not a model attack-success rate. A spaced “API key” exfiltration
request now gets the existing advisory signal; permissions remain unchanged.

The final focused six-file run passed 61 tests/295 assertions. Typecheck and
lint passed. The restricted agent environment explicitly
reported OS enforcement unavailable. The root's full-access macOS qualification
passed (1 test/3 assertions), recorded at
`/private/tmp/ur-frontier-sandbox-qualified.log`: actual benign write, fake
private-file denial, outside-workspace write denial, fake credential removal,
allowed loopback HTTP host and denied alternate hostname. The local HTTP
fixture uses `curl --noproxy ""` to exercise the runtime proxy because its
normal `NO_PROXY` intentionally bypasses loopback. No external service, model
or real credential was used. Linux/Windows enforcement and broad model-based
attack success are not established by these tests.
